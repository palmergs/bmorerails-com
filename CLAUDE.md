We are building a replacement of the old rails website bmoreonrails.org (this version will be .com) that will support the Baltiomre meetup group Bmore on Rails.

The old version of the website is available in the repo ( https://github.com/bmoreonrails/bmoreonrails.org ). We do not need to mimic **any** of this code, but if there are design questions then this is a good place to start.

Here are our constraints:
* Tailwindcss
* Hero section
* Events section with Luma integration to display events ( https://luma.com/bmore-on-rails — calendar id `cal-dlH2sPWE7XDrZUW`; note the originally-noted `/cja7x708` is a single event, not the calendar )
* Sponsor section
* **mobile first**!!!
* Easy to deploy (kamal?) and maintain

Here are our design asthetic:
* We are proud of Baltimore (waterfront, row homes, urban)
* We **love** Ruby on Rails and the Ruby language
* We are inclusive and support our community and have a strong code of conduct
